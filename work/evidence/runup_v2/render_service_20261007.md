# Render 런업 별도 서비스 증거 (2026-10-07)

## 변경 (로컬만, 배포·푸시 없음)
- `render.yaml`: `runup-scanner` 웹 서비스 추가(free). 기존 단타 서비스 유지.
  - 실행: `runup_app.py` 단독 (데몬 없음, 트래픽 없을 때 sleep 가능)
  - 비밀값은 전부 `sync: false` — 사용자가 Render 화면에서 직접 입력해야 함
- 푸시·배포는 사용자 명시 승인 전 금지. 현 상태 로컬 파일만.

## 무료 한도 정리(2개 합산)
- 시간: 둘 다 24시간 상시 가동이면 초과. 단타 데몬 끄기 + 트래픽 없을 때 sleep이면 수집 가능
- 전송·DB: 5GB·쓰기량 공유. 보관 상한 코드가 선행 과제(잔여)
