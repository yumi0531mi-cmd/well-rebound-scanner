## 발견·수정한 실제 결함
1. 다중 제안 저장 불가(충돌): `save_proposal`이 `command_id=""` 고정 삽입,
   `allocations.command_id` UNIQUE와 충돌해 2번째 제안부터 `IntegrityError`.
   → `save_proposal(..., command_id=None)`는 미지정 시 결정적 제안 ID 사용.
2. 보유수량 오류 삼킴(위험): exposures 집계가 `except: pass/continue`로 DB·파싱
   오류를 0 보유로 간주 → 중복 배분 가능. → 조회 실패·파싱 실패는 차단 오류로 변경,
   집계 대상은 `status='OPEN'`으로 한정.
3. 빈 제안 침묵(오류): 적격 0·시세 없음·세션 없음이어도 `[]` 반환 → 화면에 `[]` 표시.
   → `CONFIG_REQUIRED/NAV/시세/세션/현금` 사유별 `ValueError` 차단으로 변경.
4. 대기 목록 조회 무방비(오류): 화면 렌더 중 DB 오류 시 앱 크래시 가능.
   → `try/except` 후 오류 표시·빈 목록으로 변경.
