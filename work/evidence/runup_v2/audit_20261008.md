# 전수 구조 감사 증거 (2026-10-08)

## 잡은 구조 버그: 조건부 import 바인딩
- `render()` 안 `if model.latest:` 블록 속 `from ... import ko_table`이
  함수 전체 스코프를 오염시켜, 계산 전 빈 DB에서 `UnboundLocalError` 발생.
- 증상: 검토 대기 아래 빨간 박스. 계산된 DB에선 안 나타나서 검사를 통과했음.
- 수정: import를 함수 최상단으로 이동. `commands.py`·`collection.py`·`handlers.py`·
  `read_models.py`·`remote.py`·`database.py`·`jobs.py`·`runup_app.py` 전수 점검, 동일 패턴 없음.

## 검사 구멍 수정
- 기존 렌더 검사는 `app.exception`(처리 안 된 예외)만 봤다. 화면 에러 박스(`app.error`)는
  안 봐서 빨간 박스가 떠도 통과했다. 렌더 검사 전부(4곳)에 에러 박스 없음 assert 추가.
- 계산 전 빈 화면 전용 회귀 검사 추가(`test_render_no_scan_no_errors`, PC·모바일).
